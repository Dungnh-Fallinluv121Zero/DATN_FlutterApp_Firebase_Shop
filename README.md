BestLook App

📌 Giới thiệu

Đây là một ứng dụng bán sách trực tuyến được xây dựng bằng Flutter và sử dụng Firebase để quản lý dữ liệu. Ứng dụng giúp người dùng tìm kiếm, mua sách và quản lý đơn hàng một cách dễ dàng.

🚀 Tính năng chính

📚 Danh mục sách: Hiển thị danh sách sách theo thể loại.

🔍 Tìm kiếm: Tìm kiếm sách theo tên, tác giả hoặc danh mục.

🛒 Giỏ hàng: Thêm, xoá và cập nhật số lượng sách trong giỏ hàng.

💳 Thanh toán: Hỗ trợ thanh toán qua PayPal.

📦 Quản lý đơn hàng: Xem trạng thái đơn hàng và lịch sử mua hàng.

🛠️ Công nghệ sử dụng

Flutter: Xây dựng giao diện và logic ứng dụng.

Firebase Firestore: Quản lý dữ liệu sản phẩm, đơn hàng.

Firebase Authentication: Xác thực người dùng.

Firebase Storage: Lưu trữ hình ảnh sách.

Provider: Quản lý trạng thái ứng dụng.

PayPal SDK: Tích hợp thanh toán trực tuyến.

Chart.js + Vue.js: Phát triển dashboard quản trị.

📦 Cài đặt & Chạy ứng dụng

1. Cài đặt Flutter

Tải và cài đặt Flutter SDK

2. Clone dự án

git clone https://github.com/your-repo/online-bookstore.git
cd online-bookstore

3. Cài đặt dependencies

flutter pub get

4. Cấu hình Firebase

Thêm tệp google-services.json (Android) và GoogleService-Info.plist (iOS) vào thư mục tương ứng.

5. Chạy ứng dụng

flutter run
